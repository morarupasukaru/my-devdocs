    * "Commodore 64/128 Assembly language programming", Mark Andrews, Howard W. Sams & Co. publ., ISBN 0-672-22244-5, First ed. (1986). 
  * The Commodore 64 Programmer's Reference Guide (1982) is the definitive technical manual for the C64, covering BASIC programming, 6502 machine language, KERNAL routines, and hardware I/O. It includes vital, though sometimes inaccurate, memory maps, sprite graphics, and sound synthesis details for the SID chip. ClassicCMP +4
  * While highly regarded, the guide's explanation of memory locations 0 and 1 is less thorough than that found in Mapping the Commodore 64. Other recommended resources include Machine Language for the Commodore 64 and Mastering the Commodore 64.
